# Calculadora em C

## Sobre o projeto

Este projeto consiste em uma calculadora desenvolvida em linguagem C, inicialmente criada como atividade acadêmica e reconstruída para fins de estudo e portfólio.

O programa permite realizar operações matemáticas básicas por meio do terminal.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Verificação de divisão por zero

## Tecnologias utilizadas

- Linguagem C
- GCC
- Visual Studio Code

## Como executar

### 1. Clonar o repositório

```bash
git clone LINK_DO_REPOSITORIO
```

### 2. Acessar a pasta

```bash
cd calculadora-linguagem-c
```

### 3. Compilar

```bash
gcc calculadora.c -o calculadora.exe
```

### 4. Executar no Windows

```powershell
.\calculadora.exe
```

## Aprendizados

Este projeto permite praticar lógica de programação, variáveis, estruturas condicionais, entrada e saída de dados e operações matemáticas em C.
